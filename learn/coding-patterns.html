Coding Interview Patterns: the Blind 75 by Technique

The 75 problems in Steps 3–4 of the study plan are not 75 separate facts. They are about fifteen patterns, each worn in a few disguises. This chapter teaches the patterns, animates the ones that are hard to see in your head, gives you real Python solutions you can run, and ends with a map from every one of the 75 (numbered as in the plan) to its pattern and the one sentence that unlocks it.

1. How to solve a problem you have never seen

The plan gives you a 45-minute cap and a ten-step protocol (brute force → simplify → visualize → optimize → test → explain → bullets → pseudocode → signatures → implementation). Interviewers score the same thing that protocol trains: a visible, repeatable process. In practice it compresses to a loop you should be able to run on autopilot:

PhaseMinutesWhat you do out loud
Understand3–5Restate the problem in your words. Ask about input size, value ranges, duplicates, empty input, whether the input is sorted, what to return on failure. Write one tiny example and one edge case.
Match2–3Name the candidate pattern(s): "sorted + pair → two pointers", "substring with a constraint → sliding window", "count the ways → DP", "dependencies → topological sort". Say the brute force and its complexity first; it is your safety net.
Plan5–8Pseudocode or bullets. State the invariant your loop maintains ("window never contains a repeat"). State the target complexity and why it is achievable.
Implement12–18Write clean code top-down: signature, then skeleton, then the body. Narrate decisions, not keystrokes. Prefer clarity over cleverness; a helper function is free.
Review3–5Trace your example through the code by hand. Check off-by-ones, empty input, single element, all-equal values, negative numbers, overflow (not in Python, but say it).
Evaluate2Time and space, and the trade you would make with more time ("the O(n log n) patience sort for LIS").

When you are stuck for more than five minutes at the Match phase, the plan's rule applies: finish the 45 minutes, then watch the matching Aditya Verma tutorial and re-solve the next day. Being stuck is data about which pattern you have not yet internalized.

2. Arrays & hashing

The first pattern is the oldest trade in computing: spend memory to avoid a second pass. A hash map turns "have I seen the thing that would complete this?" into O(1). The second is running state: a single scan that carries just enough summary of the prefix (the minimum so far, the best sum ending here, the product of everything to my left) to make the decision at each index without looking back.

# #1 Two Sum — hash map of complements. O(n) time, O(n) space.
def two_sum(nums, target):
    seen = {}                          # value -> index
    for i, x in enumerate(nums):
        if target - x in seen:         # the partner was already scanned
            return [seen[target - x], i]
        seen[x] = i                    # insert AFTER checking: a number can't pair with itself

# #2 Best Time to Buy and Sell Stock — running minimum. O(n), O(1).
def max_profit(prices):
    lo, best = float('inf'), 0
    for p in prices:
        lo = min(lo, p)                # cheapest buy so far
        best = max(best, p - lo)       # sell today against that buy
    return best

# #4 Product of Array Except Self — prefix pass, then suffix pass in place. O(n), O(1) extra.
def product_except_self(nums):
    n = len(nums); out = [1] * n
    for i in range(1, n):              # out[i] = product of everything left of i
        out[i] = out[i-1] * nums[i-1]
    suffix = 1
    for i in range(n-1, -1, -1):       # multiply by product of everything right of i
        out[i] *= suffix
        suffix *= nums[i]
    return out

# #5 Maximum Subarray — Kadane. "Best sum ending here" is either extend or restart.
def max_subarray(nums):
    best = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)          # if the running sum went negative, it only hurts: restart
        best = max(best, cur)
    return best

# #6 Maximum Product Subarray — negatives flip sign, so track BOTH max and min ending here.
def max_product(nums):
    best = hi = lo = nums[0]
    for x in nums[1:]:
        cands = (x, hi * x, lo * x)
        hi, lo = max(cands), min(cands)
        best = max(best, hi)
    return best

# #31 Longest Consecutive Sequence — set, and only start counting from run starts. O(n).
def longest_consecutive(nums):
    s, best = set(nums), 0
    for x in s:
        if x - 1 not in s:             # x begins a run; each element is visited O(1) times overall
            length = 1
            while x + length in s: length += 1
            best = max(best, length)
    return best

Animation 1: Kadane's algorithm — extend or restart

Bars are the array. The green bracket is the subarray whose sum is "current" (best ending at the cursor); the blue bracket is the best seen so far. When the running sum drops below the next element on its own, the bracket restarts — that is the whole algorithm. Notice it never needs to look back.

Related one-liners: #3 Contains Duplicate is len(set(nums)) < len(nums); #53 Valid Anagram compares two Counters (or 26-slot arrays); #54 Group Anagrams keys a dict by the sorted string (or the 26-count tuple) — O(n·k log k); #59 Encode/Decode Strings is length-prefixing ("5#hello") so any character is safe.

3. Two pointers & sliding window

Both patterns exploit monotonicity: some quantity only moves one way as a pointer advances, so a pointer never has to go back. Two pointers on a sorted array: if the pair sum is too small, only moving the left pointer right can help. A sliding window over a sequence: if the window violates a constraint, shrinking from the left is the only fix, and once it is valid, growing from the right is the only way to find longer answers. The invariant you state in the Plan phase is "the window is always valid after the inner loop."

# #9 3Sum — sort, fix one, two-pointer the rest, skip duplicates. O(n²).
def three_sum(nums):
    nums.sort(); out = []
    for i in range(len(nums) - 2):
        if i and nums[i] == nums[i-1]: continue          # skip duplicate anchors
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0: l += 1
            elif s > 0: r -= 1
            else:
                out.append([nums[i], nums[l], nums[r]])
                l += 1
                while l < r and nums[l] == nums[l-1]: l += 1   # skip duplicate pairs
    return out

# #10 Container With Most Water — move the SHORTER wall; moving the taller can never help. O(n).
def max_area(h):
    l, r, best = 0, len(h) - 1, 0
    while l < r:
        best = max(best, (r - l) * min(h[l], h[r]))
        if h[l] < h[r]: l += 1
        else: r -= 1
    return best

# #50 Longest Substring Without Repeating Characters — variable window + last-seen index. O(n).
def length_of_longest_substring(s):
    last, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:   # repeat inside the window: jump left past it
            left = last[ch] + 1
        last[ch] = right
        best = max(best, right - left + 1)
    return best

# #51 Longest Repeating Character Replacement — window valid iff size - maxfreq <= k.
def character_replacement(s, k):
    count, left, maxf, best = {}, 0, 0, 0
    for right, ch in enumerate(s):
        count[ch] = count.get(ch, 0) + 1
        maxf = max(maxf, count[ch])          # maxf never needs to decrease: a stale high value only keeps the window from shrinking below a size we already achieved
        if (right - left + 1) - maxf > k:
            count[s[left]] -= 1; left += 1
        best = max(best, right - left + 1)
    return best

# #52 Minimum Window Substring — expand until all needs met, then shrink while still met. O(|s| + |t|).
from collections import Counter
def min_window(s, t):
    need, missing = Counter(t), len(t)
    left, best = 0, (0, float('inf'))
    for right, ch in enumerate(s):
        if need[ch] > 0: missing -= 1       # this char was still required
        need[ch] -= 1
        while missing == 0:                  # window covers t: try to shrink
            if right - left < best[1] - best[0]: best = (left, right)
            need[s[left]] += 1
            if need[s[left]] > 0: missing += 1   # we just dropped a required char
            left += 1
    return '' if best[1] == float('inf') else s[best[0]:best[1]+1]

# #56 Valid Palindrome — two pointers skipping non-alphanumerics. #57/#58 use expand-around-center:
def count_palindromes(s):                     # #58 Palindromic Substrings, O(n²)
    total = 0
    for center in range(2 * len(s) - 1):     # 2n-1 centers: each char and each gap
        l, r = center // 2, center // 2 + center % 2
        while l >= 0 and r < len(s) and s[l] == s[r]:
            total += 1; l -= 1; r += 1
    return total

Animation 2: sliding window with a character map (#50)

The right edge advances one character per step. When the new character already sits inside the window, the left edge jumps just past its previous position (the "last seen" map on the right makes that a single lookup, not a scan). The best window so far is drawn underneath. Total work is O(n) because each edge only ever moves right.

Fast/slow pointers are two pointers on a linked list or implicit sequence: Floyd's cycle detection (#41) advances one pointer by 1 and the other by 2; if they ever meet there is a cycle. The same trick finds the middle of a list (slow is at the middle when fast reaches the end) — used in #45 Reorder List.

4. Binary search

Binary search is not "search a sorted array". It is: a predicate that is false…false…true…true over a range lets you find the boundary in O(log n). Sorted arrays are the obvious case; rotated arrays, "minimum capacity such that…", and "first version that is bad" are the same thing with a different predicate. Write it with half-open bounds and a loop invariant and you will never fence-post it: keep lo such that the answer is in [lo, hi], and shrink until they meet.

# #7 Find Minimum in Rotated Sorted Array — predicate: nums[mid] > nums[hi] means the min is to the right.
def find_min(nums):
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] > nums[hi]: lo = mid + 1     # rotation point is strictly right of mid
        else: hi = mid                            # mid could itself be the minimum
    return nums[lo]

# #8 Search in Rotated Sorted Array — one half is always sorted; check whether the target lies in it.
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target: return mid
        if nums[lo] <= nums[mid]:                 # left half sorted
            if nums[lo] <= target < nums[mid]: hi = mid - 1
            else: lo = mid + 1
        else:                                     # right half sorted
            if nums[mid] < target <= nums[hi]: lo = mid + 1
            else: hi = mid - 1
    return -1

# Binary search on the ANSWER (not in Blind 75 but the pattern interviewers love):
# "min ship capacity to deliver in D days" = smallest cap such that feasible(cap) is True.
def first_true(lo, hi, feasible):
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid): hi = mid
        else: lo = mid + 1
    return lo

Animation 3: finding the minimum of a rotated array (#7)

lo and hi bracket the rotation point. Each step compares the middle element with the rightmost one: larger means the drop is to the right, so lo jumps past mid; otherwise the minimum is mid or to its left. Half the range dies per step.

5. Stacks, monotonic stacks & intervals

A stack solves "match the most recent open thing" (#55 Valid Parentheses) and, as a monotonic stack, "for each element, the next greater/smaller one" in O(n) — daily temperatures, histogram areas. Intervals are a sort-then-sweep pattern: sort by start, walk once, and keep a running "current merged interval"; the only question at each step is overlap or not.

# #55 Valid Parentheses — stack of expected closers. O(n).
def is_valid(s):
    pair, stack = {')': '(', ']': '[', '}': '{'}, []
    for ch in s:
        if ch in pair:
            if not stack or stack.pop() != pair[ch]: return False
        else: stack.append(ch)
    return not stack

# #36 Merge Intervals — sort by start, extend or push. O(n log n).
def merge(intervals):
    intervals.sort(); out = []
    for s, e in intervals:
        if out and s <= out[-1][1]: out[-1][1] = max(out[-1][1], e)   # overlap: extend
        else: out.append([s, e])
    return out

# #35 Insert Interval — three phases: before, overlapping (merge into one), after. O(n).
def insert(intervals, new):
    out, i, n = [], 0, len(intervals)
    while i < n and intervals[i][1] < new[0]: out.append(intervals[i]); i += 1
    while i < n and intervals[i][0] <= new[1]:
        new = [min(new[0], intervals[i][0]), max(new[1], intervals[i][1])]; i += 1
    out.append(new)
    return out + intervals[i:]

# #37 Non-overlapping Intervals — greedy: keep the interval that ENDS earliest. O(n log n).
def erase_overlap_intervals(intervals):
    intervals.sort(key=lambda x: x[1]); removed, end = 0, float('-inf')
    for s, e in intervals:
        if s >= end: end = e          # compatible: keep it
        else: removed += 1            # conflicts with a kept interval that ends earlier: drop this one
    return removed

# #38 Meeting Rooms: sort, check intervals[i][0] < intervals[i-1][1]. #39 Meeting Rooms II — min-heap of end times:
import heapq
def min_meeting_rooms(intervals):
    intervals.sort(); ends = []
    for s, e in intervals:
        if ends and ends[0] <= s: heapq.heapreplace(ends, e)   # a room frees up: reuse it
        else: heapq.heappush(ends, e)                            # need a new room
    return len(ends)

Animation 4: merging intervals on a timeline (#36)

Intervals are sorted by start (top rows). The sweep takes them one at a time: if the next one starts at or before the current merged interval's end, the merged interval stretches; otherwise it is closed and a new one begins. Output accumulates at the bottom.

6. Linked lists

Linked-list problems are pointer choreography. Two habits remove almost all bugs: a dummy head so the "first node" is never a special case, and saving the next pointer before you overwrite it. Draw three boxes and arrows on paper before you write a line.

# #40 Reverse Linked List — iterative. prev ← cur ← nxt, one step at a time. O(n), O(1).
def reverse_list(head):
    prev, cur = None, head
    while cur:                     #   prev   cur    nxt
        nxt = cur.next             #   [a] <- [b]    [c] -> ...   (save c first)
        cur.next = prev            #   [a] <- [b]    [c]          (flip b's arrow)
        prev, cur = cur, nxt       #          prev   cur          (advance both)
    return prev

# #41 Linked List Cycle — Floyd's tortoise and hare. O(n), O(1).
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast: return True
    return False

# #42 Merge Two Sorted Lists — dummy head + tail pointer. O(n + m).
def merge_two(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val: tail.next, a = a, a.next
        else: tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next

# #43 Merge K Sorted Lists — min-heap of (val, index, node). O(N log k). Tie-break on index: nodes aren't comparable.
def merge_k(lists):
    heap = [(l.val, i, l) for i, l in enumerate(lists) if l]; heapq.heapify(heap)
    dummy = tail = ListNode()
    while heap:
        _, i, node = heapq.heappop(heap)
        tail.next = tail = node
        if node.next: heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next

# #44 Remove Nth From End — two pointers n apart, from a dummy so removing the head works. O(n).
def remove_nth_from_end(head, n):
    dummy = ListNode(0, head); lead = lag = dummy
    for _ in range(n): lead = lead.next
    while lead.next: lead, lag = lead.next, lag.next
    lag.next = lag.next.next
    return dummy.next

# #45 Reorder List — find middle (fast/slow), reverse second half, interleave. O(n), O(1).
def reorder_list(head):
    slow = fast = head
    while fast and fast.next: slow, fast = slow.next, fast.next.next
    second, slow.next = reverse_list(slow.next), None
    first = head
    while second:
        nxt1, nxt2 = first.next, second.next      # save both continuations before rewiring
        first.next, second.next = second, nxt1    # first -> second -> (old first.next)
        first, second = nxt1, nxt2                # advance along the original lists

7. Trees, BSTs & tries

Every tree problem is one of three traversals plus a question of what information flows up (post-order: compute from children) or down (pre-order: pass bounds/paths). BFS with a queue gives level structure; DFS gives paths. BSTs add the ordering invariant: in-order traversal is sorted, and bounds propagate downward. A trie is a tree keyed by characters — the structure that makes prefix queries O(length).

# Templates
def dfs(node):                               # post-order: info flows UP
    if not node: return BASE
    left, right = dfs(node.left), dfs(node.right)
    return combine(node, left, right)

from collections import deque
def bfs(root):                               # level order
    out, q = [], deque([root] if root else [])
    while q:
        level = []
        for _ in range(len(q)):              # exactly one level per outer iteration
            n = q.popleft(); level.append(n.val)
            if n.left: q.append(n.left)
            if n.right: q.append(n.right)
        out.append(level)
    return out                               # this IS #64 Level Order Traversal

# #60 Max Depth: 1 + max(dfs(l), dfs(r)).   #62 Invert: swap children, recurse.   #61 Same Tree / #66 Subtree:
def same(a, b):
    if not a or not b: return a is b
    return a.val == b.val and same(a.left, b.left) and same(a.right, b.right)
def is_subtree(root, sub):
    return bool(root) and (same(root, sub) or is_subtree(root.left, sub) or is_subtree(root.right, sub))

# #63 Binary Tree Maximum Path Sum — post-order; return best "arm", update global best with both arms.
def max_path_sum(root):
    best = float('-inf')
    def gain(n):
        nonlocal best
        if not n: return 0
        l, r = max(gain(n.left), 0), max(gain(n.right), 0)   # negative arms are dropped
        best = max(best, n.val + l + r)                       # path bends at n
        return n.val + max(l, r)                              # only one arm can continue upward
    gain(root); return best

# #68 Validate BST — pass bounds down. The classic bug: comparing only with the parent.
def is_valid_bst(root, lo=float('-inf'), hi=float('inf')):
    if not root: return True
    if not lo < root.val < hi: return False
    return is_valid_bst(root.left, lo, root.val) and is_valid_bst(root.right, root.val, hi)

# #69 Kth Smallest in BST — in-order is sorted; stop at k. #70 LCA of BST — walk from root by value:
def lca_bst(root, p, q):
    while root:
        if p.val < root.val and q.val < root.val: root = root.left
        elif p.val > root.val and q.val > root.val: root = root.right
        else: return root                         # split point (or one equals root)

# #67 Construct from Preorder + Inorder — preorder[0] is the root; its inorder index splits left/right.
def build_tree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}; it = iter(preorder)
    def build(lo, hi):                            # inorder slice [lo, hi)
        if lo >= hi: return None
        root = TreeNode(next(it)); m = idx[root.val]
        root.left = build(lo, m); root.right = build(m + 1, hi)   # left MUST be built first: it consumes preorder
        return root
    return build(0, len(inorder))

# #65 Serialize/Deserialize — preorder with explicit null markers.
def serialize(root):
    out = []
    def go(n):
        if not n: out.append('#'); return
        out.append(str(n.val)); go(n.left); go(n.right)
    go(root); return ','.join(out)
def deserialize(data):
    it = iter(data.split(','))
    def go():
        v = next(it)
        if v == '#': return None
        n = TreeNode(int(v)); n.left = go(); n.right = go(); return n
    return go()

# #71 Trie, #72 Add & Search with '.', #73 Word Search II (trie + grid backtracking)
class Trie:
    def __init__(self): self.root = {}
    def insert(self, w):
        node = self.root
        for ch in w: node = node.setdefault(ch, {})
        node['$'] = True
    def search(self, w, dot=False):              # dot=True enables '.' wildcards (#72)
        def go(node, i):
            if i == len(w): return '$' in node
            if w[i] == '.' and dot:
                return any(go(node[c], i + 1) for c in node if c != '$')
            return w[i] in node and go(node[w[i]], i + 1)
        return go(self.root, 0)

def find_words(board, words):                    # #73: DFS the grid, pruned by the trie. 
    trie = Trie()
    for w in words: trie.insert(w)
    R, C, found = len(board), len(board[0]), set()
    def dfs(r, c, node, path):
        ch = board[r][c]
        if ch not in node: return
        nxt = node[ch]; path += ch
        if '$' in nxt: found.add(path)
        board[r][c] = '*'                        # mark visited in place
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C: dfs(nr, nc, nxt, path)
        board[r][c] = ch                         # unmark (backtrack)
    for r in range(R):
        for c in range(C): dfs(r, c, trie.root, '')
    return list(found)

Animation 5: BFS wave vs DFS dive on the same tree

Same tree, same "visit" operation, different container. BFS pulls from a queue and lights up level by level — the shape behind #64 and shortest-path problems. DFS pulls from a stack (or the call stack) and dives to a leaf before backing up — the shape behind every path, depth, and subtree problem. The container's contents are shown live.

8. Heaps

A heap answers one question in O(log n): what is the current extreme? That makes it the tool whenever you repeatedly need the smallest/largest of a changing set: top-k, k-way merge, scheduling by earliest end (#39), Dijkstra. The two-heap trick for the running median keeps the lower half in a max-heap and the upper half in a min-heap, rebalancing so their sizes differ by at most one; the median is then at the tops.

# #74 Top K Frequent — O(n log k) with a heap, or O(n) with bucket sort by frequency.
from collections import Counter
def top_k_frequent(nums, k):
    return [x for x, _ in heapq.nlargest(k, Counter(nums).items(), key=lambda kv: kv[1])]
def top_k_bucket(nums, k):
    freq = Counter(nums); buckets = [[] for _ in range(len(nums) + 1)]
    for x, f in freq.items(): buckets[f].append(x)
    out = []
    for f in range(len(buckets) - 1, 0, -1):
        out += buckets[f]
        if len(out) >= k: return out[:k]

# #75 Find Median from Data Stream — two heaps. add O(log n), median O(1).
class MedianFinder:
    def __init__(self): self.lo, self.hi = [], []       # lo: max-heap (negated), hi: min-heap
    def add_num(self, x):
        heapq.heappush(self.lo, -x)                       # 1. push to lower half
        heapq.heappush(self.hi, -heapq.heappop(self.lo))  # 2. move lower's max to upper (keeps every lo <= every hi)
        if len(self.hi) > len(self.lo):                   # 3. rebalance so lo has the extra element
            heapq.heappush(self.lo, -heapq.heappop(self.hi))
    def find_median(self):
        if len(self.lo) > len(self.hi): return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2

Animation 6: running median with two heaps (#75)

Each new number lands in the lower max-heap, its maximum is handed to the upper min-heap, then sizes are rebalanced. The two heap tops always straddle the median. Note the heaps are drawn sorted for readability — a real heap only guarantees the top.

9. Graphs

Graph problems come in a few shapes: reachability/components (flood fill with DFS/BFS, or union-find), ordering under dependencies (topological sort), shortest paths (BFS for unweighted, Dijkstra for weighted), and structure checks (is it a tree: n−1 edges and connected). Grids are graphs whose adjacency is the four directions — say that out loud and the interviewer knows you see it.

# #30 Number of Islands — flood fill. O(R·C).
def num_islands(grid):
    R, C, count = len(grid), len(grid[0]), 0
    def sink(r, c):
        if 0 <= r < R and 0 <= c < C and grid[r][c] == '1':
            grid[r][c] = '0'
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)): sink(r + dr, c + dc)
    for r in range(R):
        for c in range(C):
            if grid[r][c] == '1': count += 1; sink(r, c)
    return count

# #27 Clone Graph — DFS with an old→new map (the map doubles as "visited").
def clone_graph(node):
    seen = {}
    def go(n):
        if n in seen: return seen[n]
        copy = seen[n] = Node(n.val)
        copy.neighbors = [go(x) for x in n.neighbors]
        return copy
    return go(node) if node else None

# #28 Course Schedule — Kahn's algorithm: repeatedly remove nodes with in-degree 0. O(V + E).
def can_finish(n, prereqs):
    adj, indeg = [[] for _ in range(n)], [0] * n
    for a, b in prereqs: adj[b].append(a); indeg[a] += 1   # b -> a
    q = deque(i for i in range(n) if indeg[i] == 0); done = 0
    while q:
        u = q.popleft(); done += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return done == n                                       # leftover nodes = a cycle

# #32 Alien Dictionary — build char edges from adjacent words' first difference, then Kahn. 
def alien_order(words):
    adj = {c: set() for w in words for c in w}; indeg = {c: 0 for c in adj}
    for w1, w2 in zip(words, words[1:]):
        if len(w1) > len(w2) and w1.startswith(w2): return ''   # "abc" before "ab" is invalid
        for a, b in zip(w1, w2):
            if a != b:
                if b not in adj[a]: adj[a].add(b); indeg[b] += 1
                break
    q = deque(c for c in indeg if indeg[c] == 0); out = []
    while q:
        c = q.popleft(); out.append(c)
        for d in adj[c]:
            indeg[d] -= 1
            if indeg[d] == 0: q.append(d)
    return ''.join(out) if len(out) == len(adj) else ''

# #29 Pacific Atlantic — BFS/DFS from each ocean INWARD (water flows downhill, so search uphill).
def pacific_atlantic(h):
    R, C = len(h), len(h[0])
    def reach(starts):
        seen = set(starts); stack = list(starts)
        while stack:
            r, c = stack.pop()
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < R and 0 <= nc < C and (nr, nc) not in seen and h[nr][nc] >= h[r][c]:
                    seen.add((nr, nc)); stack.append((nr, nc))
        return seen
    pac = reach([(0, c) for c in range(C)] + [(r, 0) for r in range(R)])
    atl = reach([(R-1, c) for c in range(C)] + [(r, C-1) for r in range(R)])
    return [list(p) for p in pac & atl]

# Union-Find — #34 Connected Components, #33 Graph Valid Tree (n-1 edges AND no cycle).
class DSU:
    def __init__(self, n): self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x: self.p[x] = self.p[self.p[x]]; x = self.p[x]   # path halving
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b: return False          # already connected: this edge closes a cycle
        self.p[a] = b; return True
def count_components(n, edges):
    d = DSU(n); return n - sum(d.union(a, b) for a, b in edges)
def valid_tree(n, edges):
    if len(edges) != n - 1: return False
    d = DSU(n); return all(d.union(a, b) for a, b in edges)

# Dijkstra template (weighted shortest path) — heap of (dist, node).
def dijkstra(adj, src):
    dist = {src: 0}; pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue        # stale entry
        for v, w in adj[u]:
            if d + w < dist.get(v, float('inf')):
                dist[v] = d + w; heapq.heappush(pq, (d + w, v))
    return dist

10. Dynamic programming

DP is recursion with memory, but the useful skill is the four-step recipe: (1) define the state — what does dp[i] mean, in one sentence; (2) write the recurrence — how does dp[i] depend on smaller states, i.e. what was the last decision; (3) base cases; (4) order of evaluation (so dependencies are ready) and where the answer lives. Say these four things before coding and the implementation becomes transcription. The Blind 75 DP problems are mostly 1D "last decision" problems; two are 2D grids; the rest are the two classic subsequence problems.

# #16 Climbing Stairs — dp[i] = ways to reach step i = dp[i-1] + dp[i-2]. It's Fibonacci.
def climb_stairs(n):
    a, b = 1, 1
    for _ in range(n): a, b = b, a + b
    return a

# #17 Coin Change — dp[a] = min coins to make amount a = 1 + min(dp[a - c]) over coins. O(amount · coins).
def coin_change(coins, amount):
    dp = [0] + [float('inf')] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a: dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] < float('inf') else -1

# #21 Combination Sum IV — same shape but COUNT ordered ways: dp[a] = sum(dp[a - c]).
# (Outer loop over amount counts permutations; outer loop over coins would count combinations.)

# #22 House Robber — dp[i] = max(dp[i-1], dp[i-2] + nums[i]). #23 House Robber II: max of robbing [0..n-2] or [1..n-1].
def rob(nums):
    take, skip = 0, 0
    for x in nums: take, skip = skip + x, max(skip, take)
    return max(take, skip)
def rob_circular(nums):
    return max(rob(nums[1:]), rob(nums[:-1])) if len(nums) > 1 else nums[0]

# #24 Decode Ways — dp[i] = ways for prefix of length i; last decision = 1-digit or 2-digit chunk.
def num_decodings(s):
    dp = [1, 1 if s[0] != '0' else 0]
    for i in range(2, len(s) + 1):
        ways = dp[i-1] if s[i-1] != '0' else 0
        if 10 <= int(s[i-2:i]) <= 26: ways += dp[i-2]
        dp.append(ways)
    return dp[-1]

# #18 Longest Increasing Subsequence — O(n²) DP, then the O(n log n) patience trick.
def lis_quadratic(nums):
    dp = [1] * len(nums)                           # dp[i] = LIS ending exactly at i
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]: dp[i] = max(dp[i], dp[j] + 1)
    return max(dp, default=0)
import bisect
def lis(nums):
    tails = []                                     # tails[k] = smallest tail of an increasing subsequence of length k+1
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)

# #19 Longest Common Subsequence — 2D: dp[i][j] = LCS of a[:i], b[:j]. O(n·m).
def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            dp[i][j] = dp[i-1][j-1] + 1 if a[i-1] == b[j-1] else max(dp[i-1][j], dp[i][j-1])
    return dp[-1][-1]

# #20 Word Break — dp[i] = s[:i] is segmentable = any(dp[j] and s[j:i] in dict).
def word_break(s, words):
    words, dp = set(words), [True] + [False] * len(s)
    for i in range(1, len(s) + 1):
        dp[i] = any(dp[j] and s[j:i] in words for j in range(i))
    return dp[-1]

# #25 Unique Paths — grid DP (or the binomial C(m+n-2, m-1)). #26 Jump Game — greedy farthest reach:
def can_jump(nums):
    reach = 0
    for i, x in enumerate(nums):
        if i > reach: return False
        reach = max(reach, i + x)
    return True

11. Bit manipulation

Five problems, four idioms: n & (n-1) clears the lowest set bit (count bits by repeating until zero, #12); x ^ x = 0 and XOR is commutative, so XOR-ing all indices and values leaves the missing one (#14); shifting right by one relates a number to its half (#13 Counting Bits: bits[i] = bits[i >> 1] + (i & 1)); and addition decomposes into XOR (sum without carry) plus AND-shifted-left (the carry), iterated until the carry is zero (#11). Python integers are unbounded, so simulate 32-bit wraparound with a mask.

# #11 Sum of Two Integers — XOR is sum-without-carry, AND<<1 is the carry. 32-bit mask for Python.
def get_sum(a, b):
    MASK, MAX = 0xFFFFFFFF, 0x7FFFFFFF
    while b:
        a, b = (a ^ b) & MASK, ((a & b) << 1) & MASK
    return a if a <= MAX else ~(a ^ MASK)            # reinterpret as signed

def hamming_weight(n):                               # #12 — each iteration clears the lowest set bit
    c = 0
    while n: n &= n - 1; c += 1
    return c
def count_bits(n):                                   # #13 — O(n)
    bits = [0] * (n + 1)
    for i in range(1, n + 1): bits[i] = bits[i >> 1] + (i & 1)
    return bits
def missing_number(nums):                            # #14 — XOR everything
    x = len(nums)
    for i, v in enumerate(nums): x ^= i ^ v
    return x
def reverse_bits(n):                                 # #15 — peel bits off the right, push onto the left
    out = 0
    for _ in range(32): out = (out << 1) | (n & 1); n >>= 1
    return out

12. Backtracking & matrix tricks

Backtracking is DFS over choices: pick, recurse, un-pick. The template is always the same; what changes is the pruning. #49 Word Search is DFS on the grid where "choice" is the next cell and "un-pick" restores the cell you marked. Matrix problems in the Blind 75 are mostly index gymnastics with one idea each.

# Backtracking template
def backtrack(path, choices):
    if goal(path): record(path); return
    for c in choices:
        if not valid(c, path): continue       # prune
        path.append(c)                        # choose
        backtrack(path, next_choices(c))      # explore
        path.pop()                            # un-choose

# #49 Word Search — O(R·C·3^L)
def exist(board, word):
    R, C = len(board), len(board[0])
    def dfs(r, c, i):
        if i == len(word): return True
        if not (0 <= r < R and 0 <= c < C) or board[r][c] != word[i]: return False
        board[r][c], ch = '#', board[r][c]
        ok = any(dfs(r + dr, c + dc, i + 1) for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)))
        board[r][c] = ch
        return ok
    return any(dfs(r, c, 0) for r in range(R) for c in range(C))

# #48 Rotate Image — transpose, then reverse each row (clockwise). O(n²), in place.
def rotate(m):
    n = len(m)
    for i in range(n):
        for j in range(i + 1, n): m[i][j], m[j][i] = m[j][i], m[i][j]
    for row in m: row.reverse()

# #47 Spiral Matrix — shrink four bounds. #46 Set Matrix Zeroes — use row 0 / col 0 as the marker arrays (O(1) extra).
def spiral_order(m):
    out, top, bot, left, right = [], 0, len(m) - 1, 0, len(m[0]) - 1
    while top <= bot and left <= right:
        out += [m[top][c] for c in range(left, right + 1)]; top += 1
        out += [m[r][right] for r in range(top, bot + 1)]; right -= 1
        if top <= bot: out += [m[bot][c] for c in range(right, left - 1, -1)]; bot -= 1
        if left <= right: out += [m[r][left] for r in range(bot, top - 1, -1)]; left += 1
    return out

Which pattern? A decision walk

Ask in order. Is the input sorted, or can sorting it help? → two pointers or binary search. Is it a contiguous subarray/substring with a constraint? → sliding window (variable size) or prefix sums. Do I need "have I seen X" or grouping? → hash map/set. Is it "count the ways" or "min/max over choices with overlapping subproblems"? → DP; write the four-step recipe. Are there dependencies, components, or a grid? → graph: topological sort, union-find, flood fill, BFS for shortest unweighted. Repeatedly need the extreme of a changing set? → heap. Most-recent matching / next greater? → stack. Enumerate all configurations with pruning? → backtracking. Linked structure? → dummy head, fast/slow. Tree? → decide whether information flows up (post-order) or down (bounds), BFS only for levels. If none fit, say the brute force and look for the monotonic quantity — it is usually hiding there.
