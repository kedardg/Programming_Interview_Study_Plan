This is a short guided tour of the L L M architecture gallery page. Think of it as a museum where every notable open-weight language model from GPT-2 to today sits on the same kind of card, so you can see the whole field at once and compare any two models side by side.

First, credit where it is due. The cards are built from Sebastian Raschka's L L M architecture gallery dataset, which he publishes on GitHub under the Apache two license, and the architecture figures on each card are his, loaded from his website. The metadata file is vendored into this repository, and the page is generated from it by a build script, so the gallery can be regenerated whenever the dataset updates. Everything except the figures works offline.

Each card carries the same fact sheet. The company and release date. The decoder type: dense, sparse mixture of experts, or hybrid. The scale, with total and active parameters. The attention flavor. The layer mix, meaning how many layers of each kind. The key value cache per token in B F sixteen, which is the single most useful serving number. The context length, a one-line highlight of what makes the model interesting, and links to the technical report and the config file on Hugging Face. At the top of the page is a compare tool: pick any two models and the page shows a table with every differing field highlighted. Below it are filters for family, release year, and feature, plus a search box and a sort by smallest cache per token.

Let's walk through five contrasting models. Start with GPT-2 X L, OpenAI, November 2019. Dense. One and a half billion parameters. Attention: multi-head attention with learned absolute positional embeddings. Layer mix: forty eight M H A layers. Key value cache per token: three hundred kibibytes. Context: one thousand twenty four tokens. The highlight reads: classic GPT-2 recipe with dropout, GELU, layer norm, and full multi-head attention. This is the baseline everything else is measured against.

Now Llama 3.2 one B, Meta, September 2024. Dense, one billion parameters, grouped query attention, sixteen G Q A layers, and here is the number to notice: key value cache per token, thirty two kibibytes, with a context of one hundred twenty eight thousand. A model smaller than GPT-2 X L with ten times less cache per token and one hundred twenty five times the context. That gap is entirely G Q A plus RoPE.

Next, DeepSeek V3.2, December 2025. Sparse mixture of experts. Six hundred seventy one billion total parameters, thirty seven billion active, five and a half percent active. Attention: M L A with DeepSeek sparse attention. Sixty one M L A layers. Cache per token: sixty eight point six kibibytes. Think about that. A model four hundred times larger than Llama 3.2 one B has only about twice the cache per token, because multi-head latent attention compresses keys and values into a small latent vector. The highlight notes it adds sparse attention while keeping the multi-token prediction path.

Now a hybrid: Kimi Linear forty eight B A three B, Moonshot A I, October 2025. Sparse hybrid, forty eight billion total, three billion active. Attention: a three to one ratio of Kimi Delta Attention to M L A. Layer mix: seven M L A layers plus twenty Kimi Delta Attention layers. Cache per token: seven point nine kibibytes. Context: one million tokens. The highlight mentions no positional encoding in the M L A layers, channel-wise gating, and short convolution preprocessing. This is where the field went in 2026: most layers are cheap linear attention with a fixed state, and a few latent attention layers provide exact recall.

Finally an edge model: Gemma 4 E two B, Google, April 2026. Dense, five point one billion parameters but two point three billion effective. Attention: multi-query attention with Q K norm, unified keys and values on global layers, partial RoPE on global layers, and a four to one sliding window to global pattern. Layer mix: twenty eight sliding window plus seven global. Cache per token: thirty five kibibytes. The highlight explains the goal: a double-wide GELU M L P plus a single K V head to stay light enough for offline edge deployment. Every choice is about memory on a phone.

Try the compare tool on DeepSeek V3 versus Llama 3 and the differing rows light up: decoder type, scale, attention, cache. Then filter by the hybrid feature and sort by smallest cache per token, and you will see the 2026 cohort cluster at the bottom with single-digit kibibytes per token.
