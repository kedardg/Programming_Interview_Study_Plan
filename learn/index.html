The Interactive Notebook

Nineteen chapters that replace passive reading with animations you can step through, calculators you can argue with, and flashcards that make it stick. The arc runs from the math under everything, through deep learning and transformers, into GPUs, kernels, and the systems that train and serve LLMs — the same ground as the study plan, in notebook form. Every page works offline; open this folder with any static server (python3 -m http.server) or straight from disk.

How to use this with the plan

  • Weeks 1–4: chapters 1–3 and 8 alongside PMPP, plus Coding Patterns (18) for the Monday/Wednesday problems; decks Math, Deep Learning, GPU, Coding Patterns.
  • Weeks 5–8: chapters 4–7, 9, 10 while you build the kernels; drill Kernels + Quantization decks before each Saturday build.
  • Weeks 9–11: chapters 11–15; the inference and parallelism animations are the mental model for the vLLM exercise, and RL & Robotics (14) pairs with the Sunday robot-learning slots.
  • Weeks 12–13: chapters 16–18 plus the System Design deck — then drill all due cards daily in interview mode.
